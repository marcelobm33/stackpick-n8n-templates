# StackPick n8n Templates

Import-ready [n8n](https://n8n.io) workflows for the most expensive problem in any local business: **leads nobody answered**.

Reference patterns for WhatsApp lead response and follow-up. Configure credentials and validate each branch before production. Architecture: [car dealership AI stack](https://trystackpick.com/stacks/car-dealership-ai/).

## Free templates (`free/`)

| Template | What it does |
|---|---|
| [`whatsapp-lead-follow-up.json`](free/whatsapp-lead-follow-up.json) | New lead → instant WhatsApp reply in under 60s → sheet log → polite 24h follow-up |
| [`missed-call-whatsapp-recovery.json`](free/missed-call-whatsapp-recovery.json) | Missed phone call → WhatsApp message to the caller within seconds → missed-call volume log |

**Setup:** import the JSON into n8n (free self-hosted or [Cloud](https://trystackpick.com/reviews/n8n/)), follow the sticky notes inside each workflow. ~10 minutes each. You'll need a WhatsApp Business API account — [Wati vs respond.io compared with real pricing](https://trystackpick.com/vs/wati-vs-respond-io/).
